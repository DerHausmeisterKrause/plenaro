# Mitwirkung

Fehlerberichte und Ideen über GitHub Issues sind willkommen.

Da für Plenaro 2.0 eine freie private Community-Nutzung und eine **getrennte kommerzielle Lizenz** vorgesehen sind, bitte derzeit **keine externen Code-PRs** ohne vorab geklärte Beitrags- und Zweitlizenzierungsrechte. Eine Contributor-Vereinbarung wird vor Annahme externer Beiträge definiert.

Bitte niemals Zugangsdaten, Kundendaten, echte Tickets, Bearer-Tokens oder personenbezogene Daten in Issues oder Logs posten.
